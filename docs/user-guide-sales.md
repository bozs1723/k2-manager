# คู่มือการใช้งานสำหรับพนักงานขาย (ฝ่ายขาย / Sales Staff)

คู่มือนี้สรุป **งานประจำวันของฝ่ายขาย** บนระบบ K2 Manager ตั้งแต่เข้างาน → รับลูกค้า →
เปิดงาน → รับมัดจำ → ตรวจงานดีไซน์ → ปิดงาน เขียนแบบทำตามได้ทีละขั้น

> สิ่งที่ฝ่ายขายทำได้: สร้าง/แก้ลูกค้า · สร้าง/แก้งาน · ดูยอดเงิน · บันทึกการชำระเงิน ·
> ออกใบเสนอราคา/ใบสั่งงาน · ตรวจงานที่ดีไซเนอร์ส่งมา
> สิ่งที่ทำไม่ได้ (สิทธิ์อื่นดูแล): ยืนยันมัดจำขั้นสุดท้าย (ฝ่ายการเงิน), อนุมัติเข้าผลิต (ผู้จัดการสาขา), จัดการพนักงาน/ตั้งค่าบริษัท

---

## 1. เข้าสู่ระบบ
1. เปิดแอป (เพิ่มลงหน้าจอโฮมของมือถือได้ ใช้เหมือนแอปจริง)
2. ใส่ **ชื่อผู้ใช้ (username)** และ **รหัสผ่าน** ที่ได้รับจากเจ้าของร้าน/HR
3. ลืมรหัสผ่าน → แจ้งเจ้าของร้าน/HR รีเซ็ตให้ในเมนูตั้งค่า

---

## 2. ลงเวลาเข้า–ออกงาน (เมนู "ลงเวลา")
ทำทุกวันที่มาทำงาน

**เช็คอิน (เข้างาน)**
1. ไปเมนู **ลงเวลา**
2. กด **เช็คอิน** → แอปจะขอ **ถ่ายเซลฟี่** และ **เปิด GPS**
3. ระบบเช็กว่าอยู่ในพื้นที่สาขา (geofence) — ถ้าอยู่นอกรัศมีจะมีคำเตือน
4. มาสายระบบจะนับจำนวนนาทีที่สายให้อัตโนมัติ

**เช็คเอาท์ (เลิกงาน)**
- ก่อนกลับกด **เช็คเอาท์** + ถ่ายเซลฟี่อีกครั้ง

> ทุกเย็น 18:30 ระบบสรุป "ใครเข้า/ออก/ขาด + OT วันนี้" เข้ากลุ่ม LINE ของสาขาให้อัตโนมัติ
> เช็คอินตรงเวลาและอย่าลืมเช็คเอาท์ เพราะมีผลต่อการคิดเงินเดือน/OT

---

## 3. เมนูที่ฝ่ายขายใช้บ่อย
| เมนู | ใช้ทำอะไร |
|------|-----------|
| **แดชบอร์ด** | ภาพรวมงานวันนี้ / งานเร่งด่วน / ยอดที่ต้องตาม |
| **กล่องลูกค้า (Leads)** | ลูกค้าที่ติดต่อเข้ามา ยังไม่เปิดงาน |
| **ลูกค้า** | ฐานข้อมูลลูกค้าทั้งหมด เพิ่ม/แก้ไขข้อมูล |
| **สร้างงาน** | เปิดออเดอร์ใหม่ |
| **งานของฉัน / บอร์ดคิวงาน** | ติดตามสถานะงานที่ดูแล |
| **ใบเสนอราคา / ใบสั่งงาน** | ออก/ดาวน์โหลดเอกสารให้ลูกค้า |
| **การชำระเงิน** | บันทึกมัดจำ / ยอดคงเหลือ + แนบสลิป |
| **ปฏิทิน** | ดูกำหนดส่งงาน |

---

## 4. เพิ่มลูกค้าใหม่
1. เมนู **ลูกค้า** → **เพิ่มลูกค้า**
2. กรอก: ชื่อ, เบอร์โทร, LINE, อีเมล (ถ้ามี)
3. ลูกค้าที่ต้องการ **ใบกำกับภาษี** ให้กรอกเพิ่ม: ชื่อบริษัท, เลขผู้เสียภาษี, ที่อยู่วางบิล, อีเมลบัญชี
4. กดบันทึก — ระบบออก **รหัสลูกค้า** ให้อัตโนมัติ

> เปิดงานให้ลูกค้าใหม่ได้เลยจากหน้าสร้างงาน โดยไม่ต้องเพิ่มลูกค้าก่อนก็ได้ (ระบบบันทึกให้ในตัว)

---

## 5. สร้างงาน / ออกใบสั่งงาน (หัวใจของฝ่ายขาย)
1. เมนู **สร้างงาน**
2. เลือกลูกค้า (เดิม) หรือกรอกลูกค้าใหม่
3. กรอกรายละเอียดงาน:
   - **ประเภทงาน**: เสื้อ DTG · พิมพ์ UV · เลเซอร์คัต · ป้าย · งานอะคริลิค · พิมพ์ 3D · อื่น ๆ
   - รายละเอียด/จำนวน, **ราคา**, **มัดจำ**, **กำหนดส่ง**
   - ติ๊ก **งานด่วน** ถ้าลูกค้าต้องการเร่ง
4. กดบันทึก

⚠️ **สำคัญ:** งานที่ฝ่ายขายเปิด จะอยู่สถานะ **"รอผู้จัดการสาขายอมรับ"** ก่อน
เมื่อผู้จัดการสาขารับงานแล้ว งานจึงเดินหน้าเข้าคิวจริง

---

## 6. รับมัดจำ + แนบสลิป (เมนู "การชำระเงิน")
งานจะเข้าสู่การผลิตได้ก็ต่อเมื่อ **ผ่านขั้นมัดจำ** ลำดับสถานะการเงิน:

> รอเสนอราคา → **รอมัดจำ** → **รอตรวจสอบยอด** → **มัดจำแล้ว**

ขั้นตอนของฝ่ายขาย:
1. เปิดงาน → ส่วน **การชำระเงิน**
2. กรอก **ยอดมัดจำที่รับ** + **วันที่รับเงิน**
3. **แนบสลิป** การโอน (ถ่าย/อัปโหลด)
4. บันทึก → งานขึ้นสถานะ **"รอตรวจสอบยอด"**
5. **ฝ่ายการเงินเป็นผู้ยืนยันมัดจำขั้นสุดท้าย** → กลายเป็น **"มัดจำแล้ว"** แล้วเข้าผลิตได้

> กรณีไม่เก็บมัดจำ (ลูกค้าประจำ/เครดิต) ให้แจ้งหัวหน้าใช้สิทธิ์ "ยกเว้นมัดจำ"

---

## 7. ตรวจงานที่ดีไซเนอร์ส่งมา (Handoff)
ฝ่ายขายเป็น **ผู้ตรวจงานดีไซน์** ก่อนถึงมือลูกค้า

ลำดับ: **ดีไซเนอร์ส่งงานให้เซลตรวจ → เซลตรวจ/ยืนยัน → (อัตโนมัติ) ผู้จัดการสาขาอนุมัติเข้าผลิต**

1. มีแจ้งเตือนเมื่อดีไซเนอร์ส่งงานมา (สถานะ "รอลูกค้าอนุมัติ")
2. เปิดงาน ดูไฟล์ดีไซน์ → ส่งให้ลูกค้าดู
3. ลูกค้าโอเค → กด **ยืนยัน** (งานส่งต่อให้ผู้จัดการสาขาอนุมัติเข้าผลิต)
4. ลูกค้าขอแก้ → กด **ตีกลับ** งานเด้งกลับให้ดีไซเนอร์แก้ พร้อมใส่หมายเหตุ

---

## 8. รับยอดคงเหลือ + ปิดงาน
เมื่องานผลิตเสร็จและลูกค้ามารับ:
1. เปิดงาน → **การชำระเงิน** → กรอก **ยอดคงเหลือที่รับ** + **วันที่** + **แนบสลิป**
2. เมื่อชำระครบ สถานะการชำระจะเป็น **"ชำระครบแล้ว"**
3. ดันสถานะงานไปจน **"จัดส่ง / รับแล้ว" → "เสร็จสิ้น"**

> ยอดที่รับเข้าจริงในวันนั้น (มัดจำ + ยอดคงเหลือ) จะถูกรวมในรายงานสรุปสิ้นวัน 20:00 เข้ากลุ่ม LINE

---

## 9. ออก/ดาวน์โหลดเอกสารให้ลูกค้า
- เมนู **ใบเสนอราคา / ใบสั่งงาน** → เลือกงาน → **ดาวน์โหลด/ส่งออก** เป็นเอกสาร
- ระบบออก **เลขที่เอกสาร** ให้อัตโนมัติ
- ลูกค้าที่ขอใบกำกับภาษี ตรวจให้แน่ใจว่ากรอกข้อมูลภาษีในประวัติลูกค้าครบก่อน

---

## 10. ความหมายของสถานะงาน (ย่อ)
| สถานะ | หมายความว่า |
|-------|-------------|
| รอเสนอราคา | เพิ่งเปิด ยังไม่ตกลงราคา |
| รอมัดจำ / รอตรวจสอบยอด / มัดจำแล้ว | ขั้นการเงินก่อนเข้าผลิต |
| รับงานใหม่ / รอไฟล์ | รอข้อมูล/ไฟล์จากลูกค้า |
| กำลังออกแบบ / รอลูกค้าอนุมัติ | ดีไซน์อยู่ / รอเซล-ลูกค้าตรวจ |
| พร้อมผลิต / กำลังผลิต / ตรวจคุณภาพ / แพ็กของ | อยู่ในสายผลิต |
| จัดส่ง / รับแล้ว → เสร็จสิ้น | ปิดงาน |
| ยกเลิก | งานถูกยกเลิก |

---

## 11. ปัญหาที่พบบ่อย
- **เช็คอินไม่ได้ / ขึ้นอยู่นอกพื้นที่** → เปิด GPS ให้แม่นยำ และอยู่ในบริเวณสาขา ถ้ายังไม่ได้แจ้งหัวหน้า
- **เปิดงานแล้วไม่เดินหน้า** → ปกติ ต้องรอผู้จัดการสาขายอมรับงานก่อน
- **มัดจำแนบสลิปแล้วแต่ยังไม่ "มัดจำแล้ว"** → รอฝ่ายการเงินยืนยันยอด
- **ลืมรหัสผ่าน** → แจ้งเจ้าของร้าน/HR รีเซ็ตให้

---
