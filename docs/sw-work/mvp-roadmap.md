# Sw.Work — MVP Roadmap

เป้าหมายสุดท้าย: **SaaS สำหรับร้านป้าย ร้านพิมพ์ ร้าน UV ร้านอะคริลิค** — กรอกข้อมูลครั้งเดียว เอกสารทุกใบถูกสร้างอัตโนมัติ

## Phase 1 — MVP ✅ (ส่งมอบในเวอร์ชันนี้)

- [x] Sales Order Form กรอกครั้งเดียว (ลูกค้า/สินค้า/ขนาด/จำนวน/รูปทรง/วัสดุ/การพิมพ์/รูเจาะ/อุปกรณ์/ไฟล์/โน้ต)
- [x] เครื่องคำนวณราคาอัตโนมัติ + ส่วนลดตามจำนวน + VAT (override ได้)
- [x] สร้างเอกสารอัตโนมัติครบ 5 ใบ (Quotation / Approval / Production / QC / Delivery) ผ่าน DB trigger
- [x] SW.Quote: Export PDF, ส่งผ่าน LINE, ส่งผ่าน Email
- [x] SW.Confirm: Mockup + ช่องอนุมัติ/ขอแก้ไข + ลายเซ็น + นับรอบแก้
- [x] SW.Design: คิวกราฟิก 5 สถานะ
- [x] SW.Production: Production Sheet + White/Varnish Layer + Cut Line + Hole + QR Code
- [x] SW.QC: เช็กลิสต์ 6 ข้อ + ผ่าน/ไม่ผ่าน (ไม่ผ่านส่งกลับผลิต)
- [x] SW.Delivery: ขนส่ง/เลขพัสดุ/วันส่ง/สถานะ
- [x] แดชบอร์ด + บอร์ด pipeline + รายการออเดอร์ + ประวัติสถานะ
- [x] Database schema + RLS + Storage + Realtime publication
- [x] โหมดเดโม (ไม่ต้องตั้งค่าก็ลองใช้ได้) + เทสต์ pricing/documents

## Phase 2 — ใช้งานจริงทั้งร้าน

- [ ] ลิงก์คอนเฟิร์มสาธารณะให้ลูกค้ากดอนุมัติเองผ่านมือถือ (signed URL / Edge Function)
- [ ] แจ้งเตือน LINE OA อัตโนมัติทุกครั้งที่สถานะเปลี่ยน (ต่อยอด `line-webhook` function เดิม)
- [ ] สมุดลูกค้า `sw_customers` + autocomplete ในฟอร์มขาย + ประวัติการสั่งซื้อ
- [ ] หน้าสแกน QR จากใบสั่งผลิต → เปิดงาน/อัปเดตสถานะหน้าเครื่อง
- [ ] ตั้งค่าราคาเองต่อร้าน (ตารางอัตราวัสดุ/ตัวคูณพิมพ์ ย้ายจากค่าคงที่ไปฐานข้อมูล)
- [ ] Realtime UI (subscribe `sw_orders` ที่ประกาศ publication ไว้แล้ว)
- [ ] มัดจำ/ชำระเงิน + สลิป (เชื่อมโมดูลการเงินของ K2Smart)

## Phase 3 — SaaS

- [ ] Multi-tenant: ตาราง `sw_shops` + `shop_id` ทุกตาราง + RLS ต่อร้าน
- [ ] ระบบสมัคร/แพ็กเกจ/เก็บเงินรายเดือน (Stripe/Omise)
- [ ] โดเมนย่อยต่อร้าน + โลโก้/หัวเอกสารของร้านเอง
- [ ] รายงานเจ้าของร้าน: ยอดขาย, งานค้าง, เวลาเฉลี่ยต่อขั้น, ของเสียจาก QC
- [ ] AI ช่วยงาน: อ่านไฟล์ลูกค้าแล้วเติมสเปกอัตโนมัติ, ตอบแชทเสนอราคาเบื้องต้น
- [ ] แอปมือถือ/PWA สำหรับฝ่ายผลิต (มี PWA พื้นฐานจาก K2Smart แล้ว)

## หลักการตัดสินใจ

- เอกสารทุกใบ **เกิดจากข้อมูลชุดเดียว** — ห้ามมีฟิลด์ที่ต้องกรอกซ้ำสองที่
- ตรรกะสร้างเอกสาร/ราคา อยู่ใน `lib/sw-work/*` ที่มีเทสต์ และ mirror กับ trigger ใน DB
- ทุกฟีเจอร์ใหม่ต้องใช้ได้ทั้งโหมด demo และ cloud
