# 📋 สรุประบบ K2 Manager (อัปเดตล่าสุด)

สรุปฟีเจอร์/การตั้งค่าทั้งหมด + สิ่งที่ต้องทำต่อ

---

## 1) การสร้างงาน
- **ประเภทงาน → สาขาที่ผลิต** (ตามเครื่องจักร)
  - เสื้อ DTG, พิมพ์ 3D → **พระรามเก้า**
  - เลเซอร์คัต, ป้าย, อะคริลิค, **พวงกุญแจ**, อื่นๆ → **พะเยา**
- **เพจที่รับงาน → สาขารายได้** (แยกจากสาขาผลิต)
  - K2sign, k2 phayao → รายได้เข้า **พะเยา**
  - Sweetdesign, Fluffi → รายได้เข้า **พระรามเก้า**
- **ภาษี (VAT 7%)**: เลือกได้ — ไม่มี VAT / รวม VAT แล้ว / ยังไม่รวม (บวก 7%)
- **แนบรูปแบบงานลูกค้า** ได้หลายรูปตอนสร้างงาน
- เซลลงข้อมูล + ประสานงาน (ไม่ต้องเลือกผู้รับผิดชอบ — ผู้จัดการมอบหมาย)

## 2) อนุมัติ & มอบหมาย
- **ทุกงานต้องผ่านผู้จัดการสาขาอนุมัติ** ก่อนเข้าผลิต (ยกเว้นเจ้าของ/ผจก.สาขานั้นสร้างเอง)
- ผู้จัดการเห็น/อนุมัติ/มอบหมาย **เฉพาะงานสาขาที่ผลิตของตน** (เจ้าของทุกสาขา)
- ตอนอนุมัติ โชว์ **เพจ + สาขารายได้ + สาขาผลิต** ชัดเจน
- **หน้าจอผู้จัดการกระพริบแดง** + กล่องรายการ เมื่อมีงานรออนุมัติ (ฟรี ไม่กิน LINE)

## 3) ฝ่ายผลิต/ดีไซเนอร์
- **ดีไซเนอร์เห็นเฉพาะงานที่ถูกมอบหมายให้ตัวเอง** (ไม่เห็นของดีไซเนอร์คนอื่น)
- ฝ่ายผลิต: งานตัวเอง + งานที่ยังไม่มอบหมาย · ฝ่ายแพ็ก: ทั้งสาขา
- รายชื่อ "ผู้รับผิดชอบผลิต" = เฉพาะตำแหน่งฝ่ายผลิตจริง

## 4) การเงิน
- **เจ้าของ / ผู้จัดการ / แอดมิน / ฝ่ายการเงิน** ยืนยันมัดจำได้ (รวมบทบาทเสริม)
- รายรับแยกตาม **สาขารายได้ (เพจ)** · งานที่เสร็จแยกตาม **สาขาผลิต**

## 5) ลงเวลา / OT
- เช็คอินเซลฟี่ + GPS · ออกงานได้ตั้งแต่เวลาเลิกงานสาขา (เริ่ม 18:00) · ยืนยันก่อนออกงาน
- รายงาน OT รอบเย็น · **วันอาทิตย์/วันหยุด** = แจ้งวันหยุด + ใครมาทำ OT

## 6) แจ้งเตือน LINE (เหลือ 3 ตัว — ประหยัดโควต้า)
| เวลา | รายงาน | กลุ่ม |
|---|---|---|
| 9:00 | งานด่วน/ใกล้-เลยกำหนด (+ขั้นตอน+แผนก) | กลาง |
| 10:30 | เช็คอินเช้า | สาขา |
| 20:00 | สรุปสิ้นวัน (งานเสร็จ + เงินรับเข้า) | สาขา |

> ปิดแล้ว: เด้งทุกออเดอร์ใหม่ + ทุกการอนุมัติ (เปลืองโควต้า) — ผู้จัดการใช้หน้าจอกระพริบแทน
