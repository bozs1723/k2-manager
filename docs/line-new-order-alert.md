# แจ้งเตือน "ออเดอร์ใหม่รออนุมัติ" เข้ากลุ่ม LINE กลาง

เมื่อมีการสร้างงานที่ต้องให้ผู้จัดการสาขาอนุมัติ ระบบจะ:
1. เด้งข้อความเข้า **กลุ่ม LINE กลาง** (กลุ่มเดียวรวมทุกสาขา) ว่ามีออเดอร์ใหม่รออนุมัติ
2. ทำให้ **หน้าจอผู้จัดการกระพริบขอบแดง + แถบแจ้งเตือน** เมื่อมีงานที่ตัวเองอนุมัติได้ค้างอยู่ (ทำงานในแอปอัตโนมัติ ไม่ต้องตั้งค่า)

## ส่วนที่ต้องตั้งค่า (สำหรับแจ้งเข้า LINE)

| ส่วน | ไฟล์ |
|------|------|
| Edge Function | `supabase/functions/notify-new-order/index.ts` |
| แอปเรียกฟังก์ชันตอนสร้างงาน | `app/page.tsx` (createJob → `supabase.functions.invoke("notify-new-order", ...)`) |

### 1) เตรียมกลุ่ม LINE กลาง + เอา group id
1. สร้างกลุ่ม LINE สำหรับแจ้งออเดอร์ใหม่ → **เชิญบอท (LINE OA) เข้ากลุ่ม**
2. พิมพ์อะไรก็ได้ในกลุ่ม 1 ข้อความ → บอท (`line-webhook`) จะตอบ **Group ID** (`Cxxxxxxxx...`)

### 2) ตั้ง Secret ของ Edge Function
Supabase → Edge Functions → Secrets เพิ่ม:
```
ORDER_NOTIFY_GROUP_ID = Cxxxxxxxxxxxxxxxx   (group id จากขั้นที่ 1)
```
(`LINE_CHANNEL_ACCESS_TOKEN` มีอยู่แล้ว · `SUPABASE_URL` / `SUPABASE_SERVICE_ROLE_KEY` มีให้อัตโนมัติ)

### 3) Deploy ฟังก์ชัน
- Supabase → Edge Functions → Deploy a new function ชื่อ `notify-new-order` วางโค้ดจากไฟล์
  หรือ `supabase functions deploy notify-new-order`
- **เปิด Verify JWT ไว้ได้** (ค่าเริ่มต้น) — แอปเรียกด้วย token ของผู้ล็อกอินอยู่แล้ว เฉพาะคนล็อกอินถึงเรียกได้

## ทดสอบ
- ให้เซลสร้างงาน 1 งาน (งานจะอยู่สถานะ "รอผู้จัดการสาขายอมรับ") → กลุ่ม LINE กลางต้องเด้งข้อความ
- ผู้จัดการสาขานั้นล็อกอินในแอป → ขอบจอจะกระพริบแดง + มีแถบ "มีงานรออนุมัติ N งาน — กดเพื่ออนุมัติ"

## หมายเหตุ
- จะแจ้งเฉพาะงานที่ `acceptance = 'pending'` (งานที่เจ้าของ/ผู้จัดการสาขานั้นสร้างเอง = อนุมัติอัตโนมัติ จะไม่แจ้ง)
- ถ้ายังไม่ตั้ง `ORDER_NOTIFY_GROUP_ID` ฟังก์ชันจะข้ามการแจ้ง LINE เฉยๆ (ไม่ error) — ส่วนหน้าจอกระพริบยังทำงานปกติ
